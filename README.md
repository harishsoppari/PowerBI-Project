# PowerBI-Project
# Business Problem
Agricultural data is available in large and complex datasets, making it difficult to analyse and understand. Comparing crop production across different states and districts takes time. Identifying top-performing crops and understanding changes in cultivated area and yield is also challenging. Therefore, an interactive dashboard is needed to simplify agricultural data analysis and support better decision-making.
# Business Statement
The main objective of this project is to analyse Indian agricultural data using Microsoft Power BI. It focuses on measuring crop production, cultivated area and yield across different states, districts, seasons and years. The project aims to compare agricultural performance, identify important trends and present useful insights through interactive dashboards.
# Introduction
Agriculture plays an important role in India's economy and provides livelihood to many people. This project, titled National Crop Production & Yield Analytics, uses Microsoft Power BI to explore agricultural data. It presents three interactive dashboards that help users understand crop production, compare state-wise and crop-wise performance, and explore agricultural trends through clear and meaningful visualizations.
# Data Description
The dataset contains Indian agricultural information related to crop production, cultivated area and crop yield across different states, districts, crops, seasons and years.
The project uses two datasets:
Historical dataset: 1998–99 to 2012–13.
Recent dataset: 2021–22 to 2022–23.
Dataset Columns Are :
State, District, Crop ,Year ,Production, Area , Yield
Data Cleaning:
Removed duplicate records.
Checked missing values.
Corrected data formats.
Removed invalid records.
Prepared data for Power BI analysis.

Insight: Agricultural production varies across years, and the trend helps us identify changes in production over time.

 # a). Top 10 States by Agricultural Production – Bar Chart

- This chart compares the average yield of different crops.
